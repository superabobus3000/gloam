# Генерация мира


- Схемы отличаются от 1.21: noise settings используют `material_rule`, упрощённый `noise_router` из восьми полей, `noise` с min_y/height. Aquifers — необязательный объект, не старый булев флаг.
- Material rules/conditions — отдельные реестры `worldgen/material_rule` и `worldgen/material_condition`. Условия ссылаются на `minecraft:on_floor`, `minecraft:under_floor`; правило блока использует `result_state`.
- Density functions: бинарные операции используют `left`/`right`, градиент — `minecraft:gradient` с axis/from_coordinate/to_coordinate/from_value/to_value. Noise-параметры содержат base_amplitude/base_octave/octave_count; interpolated задаёт cell_size_xz/cell_size_y внутри функции.
- Настроенные features лежат в `worldgen/feature`, а не в старом configured_feature. Lake feature в 26.3 имеет поля fluid, barrier и predicates прямо на верхнем уровне; источник истины — vanilla lake_lava из JAR 26.3. Копировать старые примеры config нельзя.
- Vanilla biome carvers включают cave/cave_extra_underground/canyon. Dungeon и fossil могут быть features: исключение только structure sets не убирает их.
- Для изоляции нового мира используем копии выбранных биомов с ключами `gloam:*`, без добавления в ванильные теги структур. Это не меняет Overworld и не делает гарантий относительно сторонних модов, вставляющих структуры во все биомы.
- Биом может перекрывать цвет неба/тумана dimension type; ночные цвета заданы также на собственных биомах. Периодический туман этим не реализуется.
- Постоянная ночь без изменения часов обычного мира: статические environmental attributes и пустой список timelines. Не применять глобальный time set или doDaylightCycle к Overworld.
- Нынешняя плотность зависит от Y и двух ограниченных двумерных шумов. Нулевой уровень Y=66..86, sea_level=32: гор/океанов нет конструктивно. Пещеры пока отключены, а не считаются готовыми.
- Климатический шум масштабирован по XZ=0.25 для достаточно крупных участков леса. 14 собственных биомов включают существующий в 26.3 dappled_forest; подбирать список по реестру точной версии.
- Изменение JSON генератора не переделывает существующие чанки, а конфигурация измерения может уже сохраняться в мире. Для этапов worldgen нужен новый тестовый мир.
- Для выбора выхода: `getUncachedNoiseBiome` с квартовыми координатами позволяет искать биом без полной генерации тысяч чанков. Высоту берём через getBaseHeight(OCEAN_FLOOR_WG), после генерации дополнительно проверяем реальный биом, воду и пересечение с существующей защищённой областью.
- Проверка region/MCA данных: palette элементов block_states в 26.3 может содержать как строку, так и compound (id/properties). Не предполагать старый Name/Properties во всех записях.
- Текущий тестовый seed 20261006: 455 full-чанков, все 14 биомов, растения и вода присутствуют, structure starts отсутствуют. Проверка одной выборки не равна проверке всех миров.
- Сохранять последний рабочий JAR до окончания проверки новой версии. После успешной проверки заменять его по прежнему имени и удалять старые артефакты, тестовые миры и временные дампы.


## Лесное освещение 0.3.1
- **26.3: `minecraft:dirt` содержит только dirt/coarse_dirt/rooted_dirt!** Проверено непосредственно в vanilla JAR. Нельзя считать его тегом всех почв: явно добавить GRASS_BLOCK, PODZOL, MUD, MUDDY_MANGROVE_ROOTS, MOSS_BLOCK, PALE_MOSS_BLOCK. Эта ошибка давала крайне редкие фонари, в основном около арок.
- Независимая очередь ForestLanterns только для gloam:realm, все 14 биомов. CHUNK_LOAD callback в 26.3 принимает `(level,chunk,generated)`; CHUNK_GENERATE устаревший, дубли дедуплицируются.
- FULL_CHUNK_STATUS_CHANGE нужен для повторной активации закэшированного чанка: CHUNK_LOAD не вызывается при каждом переходе INACCESSIBLE→FULL. Не загружать соседей рекурсивно. Отложенно проверять getChunkNow четырёх центральных чанков, поскольку future может ещё не завершиться внутри callback.
- Клетка 64×64, окно XZ=20..43 (24×24). Один фонарь, минимум между окнами соседей 64−23=41 блок, включая диагонали/отрицательные координаты. floorDiv/floorMod обязательны. Старое окно 20..31 является подмножеством, поэтому совместимость расстояний сохраняется.
- Четыре чанка с X/Z mod4 в {1,2} содержат всё окно и halo18..45. Перед размещением искать существующие фонари во всём окне и по всей высоте (section.maybeHas ускоряет), арочный декор исключать через protection.
- Реальный ствол LOGS в Manhattan2 либо корень мангрового дерева; листья над колонкой обязательны. Нужны сухой заменяемый блок и безопасный грунт. Снежный слой допускает замену. 1–6 iron_chain и hanging lantern (с0.3.2), либо наземный fallback. Вода, block entities, защищённые арки не затрагиваются.
- Waxed weathered copper lantern сохраняет состаренный вид. Реестр вместо устаревших отдельных полей Blocks; проверять null/AIR. ChunkPos имеет x()/z().
- Занятые клетки хранятся в `data/gloam-lanterns.json`, format1. Атомарная запись, flush каждые100тиков/STOPPING; повреждённый индекс останавливает декор и не перезаписывается. Перезапуск не должен добавлять второй фонарь; удалённый игроком зарегистрированный фонарь не respawn.
- Минимум41 относится к сгенерированным лесным фонарям, не аркам/деревням/ручным фонарям. Участок без подходящего дерева пропускается, а не нарушает дистанцию.
- Никакого сброса мира для backfill декора: достаточно загрузить старый участок. Не менять подтверждённый ландшафт0.2.

## Проверка headless
- На dedicated test server ставить `pause-when-empty-seconds=0`: иначе сервер без игроков через60секунд перестаёт обрабатывать очередь. RCON/forceload/save не доказывают, что прошло достаточно игровых тиков.
- Для backfill сначала создать мир с dev-only `-PskipLanterns`, сохранить, перезапустить без свойства и держать участки загруженными. `tick sprint` ускоряет тест, но нужно дождаться завершения, прежде чем снимать тикеты.
- nbtlib может превращать строки в смешанном NBT List в compound `{'': String(...)}`. Нормализатор palette должен понимать также пустой ключ, иначе большинство блоков/наземных фонарей останется невидимо в отчёте.
- Не декодировать каждый блок всего мира: сначала проверить palette на нужные блоки, затем только подходящие секции. Полный Python-перебор миллионов блоков медленный.
