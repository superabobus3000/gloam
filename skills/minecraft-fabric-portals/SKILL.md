# Арки и переходы

## Геометрия
Шаблон stone_portal.nbt 13×11×5. Оригинал только в gloam/src/main/resources/data/gloam/structure/stone_portal.nbt. Вход с запада, лестница спускается по +X. Пока все арки этой ориентации; не добавлять повороты без согласованного преобразования координат коллизии/прибытия.
Поверхность портала: локально X=10, Z=2, Y=2..4, между оградами Z=1/3. X=11 — задняя декоративная стена, не заменять. Origin Y=высота ног на поверхности−7, то есть на блок ниже исходного прототипа. Точка выхода X=9.5, Y=2, Z=2.5 относительно origin; ниже находится нижняя каменная плита. Проверять опору, коллизию и отсутствие жидкости.

## Пары
Сервер решает, когда переносить игрока. Вход 20 тиков, cooldown 80 тиков. Пассажиры и транспорт не переносятся. Прерывать накопление при выходе, смерти, посадке на транспорт; очищать временные состояния при disconnect/остановке сервера.
Сохранение: data/gloam-portals.json мира, формат 1. Поля nextId/pairs сохранены; natural и retired добавлены совместимо, отсутствующие старые поля инициализировать пустыми. Писать атомарной заменой, при повреждении не перезаписывать пустыми данными.
Естественные арки сначала unlinked, но защищены и активны. При первом использовании связывать с несвязанной аркой другого мира; если её нет, создавать выход в разрешённом биоме. Пары постоянные. Все операции на серверном потоке: два игрока не должны присвоить один выход разным парам.
Пакет фазы эффекта — только S2C: 0 отмена, 1..20 заряд, 21 прибытие. Не переносить решение о телепортации на клиент.

## Естественное размещение
NaturalPortals слушает Fabric ServerChunkEvents.CHUNK_GENERATE и кладёт подходящие задания в очередь. Один кандидат на регион 24×24 чанка (384 блока); отступы 4..19 чанков определяются seed. Проверять биом, сухость, перепад высоты <=2 и отсутствие block entities/защищённых объёмов. Шаблон целиком внутри одного чанка: локальные X=2..14, Z=6..10. Нет регистрации ванильного structure set: для поиска используется /gloam locate, не /locate structure.
Обычный мир: jungle/bamboo_jungle/sparse_jungle, old_growth_pine_taiga, old_growth_spruce_taiga, pale_garden. Gloam: свои old_growth_* и pale_garden. Не добавлять пустыни/равнины/другие биомы из удобства.
**Проверенная гонка:** CHUNK_GENERATE может прийти до публикации full-чанка в ServerChunkCache. getChunkNow возвращает null. Нельзя сразу выбрасывать задание: повторить на последующих тиках. Сейчас ограничение 200 попыток и максимум 4 задания за тик; бюджет фиксируется до цикла, чтобы одну задачу не обрабатывать несколько раз за тот же тик. Не форсировать загрузку соседей из обработчика, иначе декор может бесконечно расширять мир.
/gloam locate — административный поиск по детерминированным кандидатам с догенерацией, может размещать арку; применять в тестовой копии. /gloam link_here позволяет проверить связывание без реального игрока внутри поверхности. Эти команды не заменяют клиентский игровой тест.

## Защита
Защищать полный объём, включая воздух прохода. Level.setBlock/Level.destroyBlock mixins; отмена player break/use; фильтрация взрыва до выдачи дропа; запрет перемещения поршнями. Unprotect удаляет связь, снимает защиту, сохраняет retired-ключ, но не удаляет блоки. Несвязанную арку можно сначала link_here, затем unprotect ID.
