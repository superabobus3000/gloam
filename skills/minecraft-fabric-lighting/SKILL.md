## HiddenLights
Только Gloam, вне зарегистрированных арок/деревенских полян. До5vanilla minecraft:light[level=11,waterlogged=false] около земли, центр и4направления со смещением8XZ. Даже высоко висящий фонарь освещает землю через эти источники. Это не повышение лимита Minecraft и не шейдер; точный свет зависит от препятствий/рельефа. Коллизий и видимой модели нет; с creative light item vanilla может показать маркеры.
Почва ищется в уже доступных чанках (getChunkNow), новые соседние чанки не форсируются. Только воздух, сухость, world border, защиты/поляны соблюдаются; чужой light не усыновлять и никакие твёрдые блоки не заменять. Не ставить halo за счёт вырубки листвы.
Индекс data/gloam-lights.json,format1: lamps(anchor→set nodes),dead. Intent всей группы сохраняется атомарно до block writes. Обратная owner map восстанавливается из индекса, shared owner/corruption→failclosed без перезаписи.
При успешном Level.setBlock RETURN callback удаляет источники погибшего фонаря (команды/взрывы/игроки), а изменения owned node инвалидируют ownership. Stone/другой уровень света/waterlogged/player light не удалять вместе с бывшим фонарём. Dead set сохраняет удаление недоступных узлов до их загрузки. Maintenance не грузит мир; проверяет доступные записи. Обычная save/restart проверена, crash между index/world write не атомарен и не проверен.
Недостаток: невидимые блоки vanilla LIGHT сохранятся при полном удалении мода. Для деинсталляции требуется отдельная очистка owned nodes до удаления мода; не удалять JSON индекса, иначе ownership теряется. Не обещать автоматическую очистку без установленного мода.

Это частота **мест групп**, не количество частиц/сущностей.
FireflyAreasPayload S2C, max32BlockPos; каждые100тиков только соседние доступные чанки. Codec32roundtrip PASS, count33rejected. Нет C2Sвольного спавна/телепорта. Реальное подключение LAN двух клиентов здесь не проверялось.

Графический клиент запрещён пользователем, внешний вид проверяет пользователь.
