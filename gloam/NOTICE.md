# Происхождение материалов

Проект основан на официальном FabricMC/fabric-example-mod (ветка 26.3).
Файл LICENSE сохранён из шаблона и описывает его лицензию CC0.

Постройка stone_portal.nbt предоставлена пользователем для этого проекта.
Лицензия шаблона Fabric не объявляет эту постройку общественным достоянием.
Права на исходную постройку остаются у её правообладателя.

Новые Java-файлы, JSON, скрипты и процедурная текстура созданы в рамках этой разработки.
Текстура портала не скопирована из ресурсов Minecraft. Клиент/сервер Minecraft,
JDK и сторонние зависимости в выдаваемые архивы не включены.

Данные выбранных биомов и ограниченных озёр адаптированы из ванильных определений Minecraft 26.3. Скрипт make_worldgen.py читает точный JAR локально; сам клиент/сервер игры не распространяется.
